Developed intelligent nonlinear control scheme (software) for quadrotor helicopter (quadcopter) stability and trajectory tracking. The control scheme uses AI (machine learning) for adaptive learning to accommodate real-time changes to physical parameters. The machine learning uses a type of neural network called cerebellar model articulation controller (CMAC). Control scheme is shown to be robust to disturbances such as wind.
